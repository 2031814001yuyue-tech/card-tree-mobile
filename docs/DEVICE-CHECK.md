# 真机走查清单（10 分钟）

电脑上没法跑 Android 模拟器，下面这些只能在真机上确认。
装好 APK（当前 0.3.6）后按顺序过一遍；哪一步和「预期」不符，截图发回来即可定位。

| # | 操作 | 预期 |
|---|------|------|
| 1 | 安装 APK，首次启动 | 弹「先连上 opencode go」，粘 Key 后「保存并开始」→ 直接进空树 |
| 2 | 提一个问题（根卡片） | 流式出字；思考过程可展开；生成中按钮变「停止」 |
| 3 | 生成中把 App 切到后台再回来 | 生成继续，不中断 |
| 4 | 键盘弹出（点输入框） | composer 整体在键盘上方，不被遮住；输入框焦点环正常 |
| 5 | 刘海屏顶部 / 手势条底部 | header 和 composer 不被刘海、圆角、手势条压住 |
| 6 | 系统返回键（卡片页 → 树 → 抽屉 → 退出） | 逐层返回：卡片→树→关抽屉→关设置→真退出；不会一步闪退 |
| 7 | 树视图长按一张卡 | 弹快捷菜单（打开/编辑/引用/重答/分享/删除） |
| 8 | 全览图：拖一张卡到另一张上 | 提示「松手，挂到这张卡片下面」→ 松手 toast「已挂到」 |
| 9 | 全览图：从卡片右侧 ⊕ 拉到另一张卡 | 建立「引用」，详情页出现「引用的卡片」 |
| 10 | 卡片操作行点「分享」 | toast「长图已保存到 下载/CardTree/…」；相册/文件管理器里能看到长图 |
| 11 | 追问一条问题 | 追问挂在卡片下方；追问右下角有「编辑」小按钮 |
| 12 | 点「编辑」改追问文字并保存 | 改动立即生效，不触发重新生成 |
| 13 | 设置 → 订阅与模型：切到 Kimi Coding | Key 状态变「还没有配置」（如未粘过）；粘 Key 后模型列表变 kimi 系列 |
| 14 | 模型下拉随便展开 | 每个模型下方有灰色小字「能看图 / 上下文 1M」 |
| 15 | 外观：切四种风格 × 深浅主题 | 16 种组合即时生效；Android 状态栏颜色跟着变 |
| 16 | 联网搜索开关点亮后提问 | 回答前先出「联网搜索」资料提示；卡片底部出现来源列表 |
| 17 | 拍一张照片当附件提问（选能看图的模型） | 模型能描述图片内容 |
| 18 | 杀掉 App 进程重开 | 项目和设置都在（固定端口生效）；设置 → 数据 → 自动备份的「上次」时间在更新 |
| 19 | 设置 → 关于 → 检查更新 | 显示「网页层已是最新（0.3.6）」；下载不动时填 `https://ghproxy.net/` 到「下载镜像」再试 |
| 20 | 卸载重装 | 应用内数据清空（预期），但「下载/CardTree/backups」里的自动备份文件还在，可从「导入备份」恢复 |

> 20 条走完这个 App 就算真机验证过了。有问题的一条截图 + 一句话描述即可。
