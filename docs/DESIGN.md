# 界面设计说明（视觉语言）

这份文档记录 card-tree-mobile 的视觉系统，方便后续改动时不跑偏。

## 一个概念

**一张索引卡，沿着一条生长线，长成一棵树。**

产品不是「聊天记录」，而是一棵可以回看的树。因此界面里所有视觉决定都服务两件事：**让树看得见**、**让每张卡像一张可以抽出来看的卡**。

- 树视图用真实的线条画层级，而不是缩进 + 徽章。
- 卡片详情做成**一张纸**：问题、思考、回答、统计、操作都在同一张卡上，不拆成聊天气泡。
- 追问、引用、子卡片挂在纸面下方，用同一条生长线串起来。

## 两个字体角色

| 用途 | 字体 | 细节 |
| --- | --- | --- |
| 内容 | 系统无衬线（PingFang SC / HarmonyOS Sans / MiSans / 微软雅黑） | 正文 15px / 1.78；问题 19px / 600；树卡问题 16.5px / 600 |
| 标签与数字 | 等宽字体栈 `--ct-font-mono` | 卡片「签」、模式标签、`320 / 16092 tokens`、项目卡片数、分组小标题，全部 9.5–10.5px，字距拉开 |

等宽只用在「规格信息」上（层级、编号、计数、token、日期），正文绝不使用——这是这张界面最容易被记住的一点。

## 色板

**纸面 + 墨 + 一根生长线**，彩色只表示语义，不做装饰。

| Token | 浅色 | 深色 | 用在哪 |
| --- | --- | --- | --- |
| `--ct-paper` | `#f4f5f9` | `#101114` | 页面底色（也是浏览器的 theme-color 来源） |
| `--ct-surface` | `#ffffff` | `#191a1f` | 卡片纸面、抽屉、Sheet |
| `--ct-surface-sunken` | `#ebedf3` | `#23252c` | 思考过程、代码块这类下沉内容 |
| `--ct-ink` / `--ct-ink-soft` / `--ct-ink-faint` | `#191c23` / `#5c6273` / `#8a90a0` | `#ecedf3` / `#a4aaba` / `#717788` | 三级文字 |
| `--ct-line` / `--ct-line-strong` | `#e3e6ee` / `#d2d7e3` | `#2a2d36` / `#3a3e49` | 发丝线 / 需要立住的分隔 |
| `--ct-branch` | `#c3cbdc` | `#454b5a` | 树的生长线 |
| `--ct-blue` | `#4d6bfe` | `#6b85ff` | 只做交互：按钮、选中、链接、把手 |
| `--ct-grow` | `#2e9e6e` | `#46b884` | 只表示「已完成 / 新枝」（状态点、发散） |
| `--ct-amber` | `#b0730f` | `#d8a442` | 分支重答 |
| `--ct-danger` | `#cf4459` | `#f0736f` | 删除、出错、不能落的拖放 |
| `--ct-grain` | 黑色噪点 SVG，`opacity 0.055` | 白色纤维噪点，`opacity 0.045` | 纸面纹理（180×180 平铺；画在 `.frame` 上，header/footer/loading 透明让纹理透出来） |

模式的颜色是全应用统一的：根＝墨灰、深入＝蓝、发散＝绿、重答＝琥珀、独立＝浅灰。树视图、卡片详情、全览图三处必须一致。

## 形状与层次

- 纸面不是纯色：`body` 与 `.frame` 铺一层 180×180 的 SVG 噪点（`--ct-grain`），手机上看像有纤维的纸；卡面保持纯白/纯深，不做纹理，靠这个反差让卡片"浮"在纸上。
- 卡片：18–20px 圆角、1px 发丝边、极轻的投影（`--ct-card-shadow`）。纸面与卡片靠**亮度差 + 一条边**区分，不靠重阴影。
- 索引卡「签」：卡片左上角探出的小标签（`◦ 根卡片 L0`），纸面底 + 上圆下方（`9px 9px 2px 2px`）、无下边框，左侧一个 5px 的穿绳孔（内凹圆环），贴着纸面边缘挑出来 14px，像真的索引卡标签。
- 生长线：1px 实线，落在卡片左侧 10px。实现上挂在**卡片行**（`.row`，行高＝卡片高）而不是整个 `<li>` 上，所以 `top:50%` 一定落在卡片中线，不会因为子树高度把横枝带偏。每个父级的最后一个孩子收口，不再往下延伸。
- 抽屉里的「新的探索」用**虚线边框**，像一张还没写的卡；项目条目的卡片数 / 日期用等宽字；当前项目用品牌蓝的浅底 + 蓝色标题。
- 模型选择器：自绘的等宽字浮层（`components/base/Select`），不用系统 `<select>`；40px 触发器、mono 12px 选项、选中项蓝色 + 对勾、`max-height 320` 可滚。
- 联网搜索开关：和模式 pill 同一行、靠右（`margin-left:auto`），胶囊形、12.5px；开启是实心品牌蓝 + 白字（和「追问」一样的"已选中"语义），未开通时虚线边框 + 淡字，不抢主流程。
- 联网来源：卡片正文之后、操作行之前，一条 1px 分隔线 + mono 小标题「联网搜索 · N 条来源」；每条是 17px 圆角编号方块 + 两行标题 + mono 域名，点开原文在新标签页，整体读起来像论文的参考文献列表而不是"链接卡片"。
- 附件 chip：输入框上方一行——图片用 34px 缩略图，文本用回形针图标；都靠「名字 + 等宽大小」两行信息，移除按钮是一个 16px 的 ×。

## 动效

时间曲线统一 `--ct-ease: cubic-bezier(0.2, 0.8, 0.2, 1)`。

| 位置 | 动作 | 参数 |
| --- | --- | --- |
| 卡片详情纸面 | 换卡片时淡入 + 轻微上移 | `sheet-in` 300ms，`translateY(10px)` + `scale(.995)` → 1 |
| 树节点 | 进入时淡入 + 上移，按兄弟顺序错峰 | `node-in` 320ms，每级 `+24ms`（最多错 8 个） |
| Sheet / 抽屉 | 上滑 / 侧滑 | 220ms |
| 生成中状态点 | 缓慢呼吸 | 只在 running 时 |
| 拖拽节点 / 全览图缩放 | 实时 transform，不做弹簧 | — |

- 动效只做「出现」和「状态变化」，不做退出动画、不做整页过渡；时长不超过 320ms。
- 全局 `@media (prefers-reduced-motion: reduce)`（`design.css` 末尾）把动画与过渡收到 0.01ms，系统开了「减少动态效果」时全部静态。

## 落地位置

- Token：`app/src/app/design.css`（`main.tsx` 里在 `global.css` 之后引入，覆盖旧主题变量）——色板、字体栈、`--ct-ease`、`--ct-grain`、全局 reduced-motion 都在这里
- 树视图：`app/src/components/tree/`（`.row` 包卡片、`.children` 嵌套列表、`preview()` 去 Markdown 噪声）
- 卡片详情：`app/src/components/card/`（`.sheet` 单张纸面、`.tab` 索引标签、动效）
- 全览图：`app/src/components/overview/`（Token 已全部换成 `--ct-*`）
- 底部输入：`app/src/components/composer/`
- 抽屉 / 设置 / Sheet / 模型选择器：`app/src/components/{projects,settings,common,base}/`

> 旧 token（`--dsw-*`）仍保留给 Markdown 渲染、基础控件等未重写的部分；新写的样式一律用 `--ct-*`。

## 改动前的四条检查

1. 新颜色是不是语义色？不是语义就用墨色/线色，别新增彩色。
2. 新字号是不是落在这几档？9.5/10.5（等宽标签）、11.5、12.5、13.5、15、16.5、19、22。
3. 新动效是不是 ≤320ms、只做出现/状态变化、`prefers-reduced-motion` 下会静止？
4. 截一张 390×844 的图看：树还看得见吗？卡片还像一张卡吗？纸纹还在吗？浅色与深色都成立吗？
