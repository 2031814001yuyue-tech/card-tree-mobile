# 界面设计说明（视觉语言）

这份文档记录 card-tree-mobile 的视觉系统，方便后续改动时不跑偏。

## 一个概念

**一张索引卡，沿着一条生长线，长成一棵树。**

产品不是「聊天记录」，而是一棵可以回看的树。因此界面里所有视觉决定都服务两件事：**让树看得见**、**让每张卡像一张可以抽出来看的卡**。

- 树视图用真实的线条画层级，而不是缩进 + 徽章。
- 卡片详情做成**一张纸**：问题、思考、回答、统计、操作都在同一张卡上，不拆成聊天气泡。
- 追问、引用、子卡片挂在纸面下方，用同一条生长线串起来。

## 两个字体角色

| 用途 | 字体 | 细节 |
| --- | --- | --- |
| 内容 | 系统无衬线（PingFang SC / HarmonyOS Sans / MiSans / 微软雅黑） | 正文 15px / 1.78；问题 19px / 600；树卡问题 16.5px / 600 |
| 标签与数字 | 等宽字体栈 `--ct-font-mono` | 卡片「签」、模式标签、`320 / 16092 tokens`、项目卡片数、分组小标题，全部 9.5–10.5px，字距拉开 |

等宽只用在「规格信息」上（层级、编号、计数、token、日期），正文绝不使用——这是这张界面最容易被记住的一点。

### 四种界面风格（0.3.5 起）

上面这张表是**索引卡**（默认）的值。另外三种风格不改组件、只覆盖 token：在 `design.css` 末尾用 `body[data-style='…']`（浅色）与 `body[data-ds-dark-theme][data-style='…']`（深色）整层重定义 `--ct-*`，选择器特异性逐级压过 `:root`。`theme.ts` 在切主题 / 切风格时把 `document.body.dataset.style` 一并同步，纸面换了 `syncPageBackground()` 会让状态栏跟着换色。

| 风格 | 一句话 | 主要 token 变化 |
| --- | --- | --- |
| 索引卡（默认） | 冷白纸面 + 细噪点 + 白卡 | — |
| 素笺 | 纯白、去噪点、最简 | `--ct-grain: none`，线更浅、阴影更轻 |
| 羊皮纸 | 暖黄纸、墨带棕、暖靛强调 | 纸 `#f5efe2`、墨 `#2e2a20` 系、`--ct-blue` → `#5a5bd8`、grow/amber 各自调暖 |
| 石墨 | 冷灰纸、冷蓝、更硬的对比 | 纸 `#eef0f4`、`--ct-blue` → `#3556e0` |

风格与深浅主题是两个正交开关：`data-ds-dark-theme` 管深浅、`data-style` 管纸色，任意组合都成立。

## 形状与层次

- 纸面不是纯色：`body` 与 `.frame` 铺一层 180×180 的 SVG 噪点（`--ct-grain`），手机上看像有纤维的纸；卡面保持纯白/纯深，不做纹理，靠这个反差让卡片"浮"在纸上。
- 卡片：18–20px 圆角、1px 发丝边、极轻的投影（`--ct-card-shadow`）。纸面与卡片靠**亮度差 + 一条边**区分，不靠重阴影。
- 索引卡「签」：卡片左上角探出的小标签（`◦ 根卡片 L0`），纸面底 + 上圆下方（`9px 9px 2px 2px`）、无下边框，左侧一个 5px 的穿绳孔（内凹圆环），贴着纸面边缘挑出来 14px，像真的索引卡标签。
- 生长线：1px 实线，落在卡片左侧 10px。实现上挂在**卡片行**（`.row`，行高＝卡片高）而不是整个 `<li>` 上，所以 `top:50%` 一定落在卡片中线，不会因为子树高度把横枝带偏。每个父级的最后一个孩子收口，不再往下延伸。
- 抽屉里的「新的探索」用**虚线边框**，像一张还没写的卡；项目条目的卡片数 / 日期用等宽字；当前项目用品牌蓝的浅底 + 蓝色标题。
- 模型选择器：自绘的等宽字浮层（`components/base/Select`），不用系统 `<select>`；40px 触发器、mono 12px 选项、选中项蓝色 + 对勾、`max-height 320` 可滚。0.3.6 起选项分两行——模型名 + 灰色小字标注（`.optionHint`，10.5px 淡字：「能看图 · 上下文 1M」；上下文 ≥950K 显示成 M、≥1M 带一位小数），触发器仍只显示模型名，菜单里才给元数据。
- 联网搜索开关：和模式 pill 同一行、靠右（`margin-left:auto`），胶囊形、12.5px；开启是实心品牌蓝 + 白字（和「追问」一样的"已选中"语义），未开通时虚线边框 + 淡字，不抢主流程。
- 联网来源：卡片正文之后、操作行之前，一条 1px 分隔线 + mono 小标题「联网搜索 · N 条来源」；每条是 17px 圆角编号方块 + 两行标题 + mono 域名，点开原文在新标签页，整体读起来像论文的参考文献列表而不是"链接卡片"。
- 附件 chip：输入框上方一行——图片用 34px 缩略图，文本用回形针图标；都靠「名字 + 等宽大小」两行信息，移除按钮是一个 16px 的 ×。
- 树分支折叠按钮 `.fold`（0.3.5）：有子卡片的节点下方一行小字（mono 10.5px、淡字、active 下沉底色），展开态图标转 90°；折叠后显示「N 张子卡片」，生长线在该节点收口（`.row::after` 下半段线本来就不依赖 `<ul class=children>`，所以折叠不断线）。折叠状态记在 `localStorage`（`card-tree:collapsed`），搜索时强制全部展开。
- 流式跟随与滚动恢复（**0.3.8 重做**，`App.tsx`）：`mainRef` 挂在 `<main>` 上；`followRef` 记「离底 <120px 才跟随」，`userTouchRef` 记「手指正压在屏幕上」。**按住期间绝不程序化滚动**——Android WebView 的 scroll 事件是异步节流的，拖动中只靠 scroll 事件判停会慢半拍，出现"往上拖又被拉回底部"（0.3.5–0.3.7 的真实 bug：滚动监听挂在 `ready=false` 时刻，从来没生效过）。松手后离底近才继续跟，往回翻过就停、回到底部自动恢复。监听统一在 `ready` 之后挂。
- 浮动跳转按钮 `.jumpButton`（0.3.8，仿 DeepSeek 手机端）：内容超一屏才出现（`pageOverflow`，`scrollHeight-clientHeight>80`），40px 圆钮 fixed 右下、composer 上方；不在底部 = 「跳到底部」（跳过去并恢复跟随），已在底部 = 「回到顶部」（图标转 180°）。纸面底 + 发丝边 + 卡片影，不抢 composer 的注意力。
- 左右滑切换层级（0.3.8）：水平位移 ≥64px 且主导方向才判定（`|dy|*1.5<|dx|`），move 中一旦判水平就 `preventDefault` 压掉纵向抖动；右滑 = 上一级（浮层 → 树 → 抽屉，与 Android 返回键同构），左滑 = 下一级（树 → 最近卡片，卡片 → 全览）。`.main` 上限定 `touch-action: pan-y`，把水平手势留给应用、也免掉浏览器的历史导航误触。
- 「正在搜索…」胶囊 `.searching`（0.3.8）：搜索进行中（live.searching）替代 typing 三点，`IconSearchOutline16` 1.6s 匀速旋转 + 12.5px 文字，下沉底胶囊——比三点更明确"卡在哪一步"；追问区（followLive.searching）同样处理。
- 追问编辑小按钮 `.followUpEdit`（0.3.6）：追问内容右下角一行右对齐的小按钮（图标 + 「编辑」，13px），hover 才上底色，生成中半透明禁用——它只改文字不重跑模型，所以是"悄悄改"的权重，不进卡片操作行那种一级 chip。
- 单卡分享长图（0.3.6，`services/share.ts`）：纯 canvas 渲染 720px 宽，头部「卡片树」品牌 + 日期 + 项目名 + 3px 蓝色分隔条，正文走两档字号（放不下自动降一档），参考来源 mono 小字最多 5 条，底部一行水印；深浅色跟随当前主题。卡片操作行的「分享」chip 与树长按菜单的「分享成长图」都走它。
- 卡片合并（0.3.7）：复用引用选择器的 `.picker/.pickerItem` 样式做「并入哪张卡片」浮层，顶部一行 `.keyFine` 说明源卡会怎么转（追问 / 子卡 / 引用），候选列表只列能并的卡（排除自己、祖先、子孙、生成中），空态文案解释为什么没有候选。合并后的回答拼接用 Markdown 分隔线 `---` 隔开，问法不同时加一行 `**另一个问法：**`——让「两张卡并成一张」在读起来是连续的两段，而不是两份档案贴在一起。
- Sheet 打开宽容期（0.3.7，`components/common/Sheet.tsx`）：浮层打开后 350ms 内忽略遮罩点击。长按卡片打开快捷菜单的瞬间，抬手会被浏览器合成一次落点在遮罩上的 click，没有这个宽容期菜单会"闪开即关"；也顺带防御所有浮层刚打开时的杂散点击。Esc 与显式按钮不受影响。

## 动效

时间曲线统一 `--ct-ease: cubic-bezier(0.2, 0.8, 0.2, 1)`。

| 位置 | 动作 | 参数 |
| --- | --- | --- |
| 卡片详情纸面 | 换卡片时淡入 + 轻微上移 | `sheet-in` 300ms，`translateY(10px)` + `scale(.995)` → 1 |
| 树节点 | 进入时淡入 + 上移，按兄弟顺序错峰 | `node-in` 320ms，每级 `+24ms`（最多错 8 个） |
| Sheet / 抽屉 | 上滑 / 侧滑 | 220ms |
| 生成中状态点 | 缓慢呼吸 | 只在 running 时 |
| 联网搜索图标 | 匀速旋转 1.6s（`.searching`） | 搜索进行中；reduced-motion 下停转 |
| 拖拽节点 / 全览图缩放 | 实时 transform，不做弹簧 | — |

- 动效只做「出现」和「状态变化」，不做退出动画、不做整页过渡；时长不超过 320ms。
- 全局 `@media (prefers-reduced-motion: reduce)`（`design.css` 末尾）把动画与过渡收到 0.01ms，系统开了「减少动态效果」时全部静态。

## 落地位置

- Token：`app/src/app/design.css`（`main.tsx` 里在 `global.css` 之后引入，覆盖旧主题变量）——色板、字体栈、`--ct-ease`、`--ct-grain`、全局 reduced-motion 都在这里
- 树视图：`app/src/components/tree/`（`.row` 包卡片、`.children` 嵌套列表、`preview()` 去 Markdown 噪声）
- 卡片详情：`app/src/components/card/`（`.sheet` 单张纸面、`.tab` 索引标签、动效）
- 全览图：`app/src/components/overview/`（Token 已全部换成 `--ct-*`）
- 底部输入：`app/src/components/composer/`
- 抽屉 / 设置 / Sheet / 模型选择器：`app/src/components/{projects,settings,common,base}/`

> 旧 token（`--dsw-*`）仍保留给 Markdown 渲染、基础控件等未重写的部分；新写的样式一律用 `--ct-*`。

## 改动前的四条检查

1. 新颜色是不是语义色？不是语义就用墨色/线色，别新增彩色。
2. 新字号是不是落在这几档？9.5/10.5（等宽标签）、11.5、12.5、13.5、15、16.5、19、22。
3. 新动效是不是 ≤320ms、只做出现/状态变化、`prefers-reduced-motion` 下会静止？
4. 截一张 390×844 的图看：树还看得见吗？卡片还像一张卡吗？纸纹还在吗？浅色与深色都成立吗？
